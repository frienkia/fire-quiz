# 消防题库练习 · 消防设施操作员（中级·监控）

一个纯前端的消防设施操作员（中级·监控方向）理论刷题网页：**2999 道题**、三种题型、随机抽题、知识点去重、考试 / 练习双模式、错题本、断点续做，可"安装"到手机后**离线使用**。

在线使用：**https://frienkia.github.io/fire-quiz/**

> 题目按《消防设施操作员职业技能鉴定考核大纲（2026 年版）》中级监控方向整理，**非官方真题**，仅供复习练习。

## 功能

- **两种模式**
  - 考试模式：20 / 50 / 100 / 150 / 200 题，交卷统一评分，交卷后可在「答题卡 · 逐题解析」里逐题看答案解析
  - 练习模式：固定 200 题，选完立刻判对错并显示解析，答过锁定
- **三种题型**：单选、多选、判断，按 6 : 2 : 2 组卷；按 1 / 2 / 1 分值累加后折算百分制
- **抽题去重**：同一知识点（`g` 分组）在一套卷里只出现一次，跨题型也去重；可勾选"优先抽没做过的题"
- **逐题解析**：每道题都带解析，错题回顾可筛选"只看错题"
- **断点续做**：做到一半关掉，下次打开接着答
- **错题本 / 成绩**：存本机浏览器；支持导出 json、跨设备导入
- **手机友好**：左右滑动翻题、切题滑动过渡、可添加到主屏幕离线使用

## 计分规则

| 题型 | 每题分值 | 判分 |
| --- | --- | --- |
| 单选 | 1 分 | 选对得分 |
| 多选 | 2 分 | 全对才得分，少选 / 多选 / 错选都是 0 分 |
| 判断 | 1 分 | 选对得分 |

- 全卷按分值累加，再折算成百分制，**60 分及格**
- 例：100 题卷 = 单选 60×1 + 多选 20×2 + 判断 20×1 = 120 分，拿到 90 分即折算 75 分
- **考试模式**：交卷就按分数算，没作答的题按 0 分
- **练习模式**：只有把整套做完才折算分数；中途点「结束练习」只显示已答部分的正确率

## 本地运行

直接双击 `quiz.html` 即可（题库已内嵌，无需安装、无需联网）。

要改题库：

```bash
# 1. 在 parts/ 下加 jsonl（一行一题，或在 bank.json 里改）
# 2. 重新生成
python build.py
```

`build.py` 会校验格式、去重（题干重复 / 同组超 3 道 / 与单选题近似重复），并重新生成 `quiz.html` 和 `题库.csv`。

题型字段：

| t | 题型 | opts | ans |
| --- | --- | --- | --- |
| `s` | 单选 | 4 个 | 0~3 |
| `m` | 多选 | 4 个 | 2~3 个下标数组 |
| `j` | 判断 | `["正确","错误"]` | 0 / 1 |
